## ✨ Features

Yeh website 4 alag-alag pages se milkar bani hai:

### 1. 🏠 Home Page (`index.html`)
* **Parallax Hero Section:** Ek attractive, full-screen banner image jo scroll karne par parallax effect deti hai.
* **Highlight Cards:** Restaurant ki key features (Fresh Ingredients, Fast Delivery, etc.) ko icons ke saath display karta hai.

### 2. 🍕 Menu Page (`menu.html`)
* **Pure CSS Category Filter:** "Radio Button Hack" ka istemal karke banaya gaya ek fully functional tab system (Starters, Main Course, Desserts) jo dishes ko bina page reload kiye filter karta hai.
* **Modern Dish Cards:** Har dish ke liye image, description, price, aur hover effect wala card.

### 3. 🧑‍🍳 About Page (`about.html`)
* **2-Column Layout:** Restaurant ki story aur image ko display karne ke liye CSS Grid ka use.
* **Team & Stats Section:** Chefs ki team aur restaurant ke stats (Happy Customers, Years of Experience) ko showcase karta hai.

### 4. ☎️ Contact Page (`contact.html`)
* **Floating Labels Form:** Ek modern contact form jismein user ke click karte hi placeholder text smoothly "float" karke label ban jaata hai (pure CSS).
* **Contact Info & Map:** Google Maps embed aur contact details.

### Common Features
* **Responsive Hamburger Menu:** "Checkbox Hack" ka istemal karke banaya gaya ek smooth, animated, aur responsive navigation menu.
* **Multi-Page Linking:** Sabhi pages ek doosre se correctly linked hain.
* **Footer:** Ek consistent footer jo har page par available hai.

## 🛠️ Technologies & Concepts Used

* **HTML5:** Semantic markup (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`).
* **CSS3:**
    * **Flexbox & Grid:** Complex aur responsive layouts ke liye.
    * **`background-attachment: fixed`:** Home page par parallax effect ke liye.
    * **CSS Variables (`:root`):** Poori site mein consistent color theme aur fonts ke liye.
    * **Checkbox/Radio Hack:** Bina JavaScript ke interactive elements (Hamburger Menu aur Menu Tabs) banane ke liye.
    * **Pseudo-classes (`:checked`, `:focus`, `:not(:placeholder-shown)`):** Advanced form styling aur state management ke liye.
    * **Sibling Selector (`~`):** Checkbox hack ko power dene ke liye.
    * **Transitions & Animations:** Smooth hover effects aur page load animations ke liye.
    * **Media Queries:** Poori site ko mobile, tablet, aur desktop par responsive banane ke liye.
